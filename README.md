# Nanoqoi's Balatro Additions

A [Balatro](https://www.playbalatro.com/) mod starring our five cats, our dog Loki and a few VTubers. It adds 11 jokers, a seal, an edition, a boss blind, a booster pack, a deck and a challenge.

**[Download the latest release](../../releases/latest)**. Setup takes a few minutes; see [Installing](#installing).

## Jokers

Numbers are what each card shows when you first find it. Kitties and Puppers grow from there, and most of them can go higher the more animals you have out.

### The Kitties

Every cat in play raises the maximum each of the others can reach.

By default only this mod's jokers show up in shops and packs. To mix the base game's jokers back in, turn off **Only Nanoqoi's Balatro Additions jokers appear** in the mod's settings.

## Installing

You need [Lovely](https://github.com/ethangreen-dev/lovely-injector) and [Steamodded](https://github.com/Steamodded/smods) `1.0.0~ALPHA-1225a` or newer. Every [release](../../releases) has step-by-step instructions for Windows, macOS and Linux. In short:

1. Install Lovely and Steamodded.
2. Download `NanoqoiAdditions-v….zip` from the latest release.
3. Unzip it into your `Mods` folder so you end up with `Mods/NanoqoiAdditions/NanoqoiAdditions.lua`.

To update, delete the old `Mods/NanoqoiAdditions` folder and unzip the new one.
